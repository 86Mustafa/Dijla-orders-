طلبيات دجلة - نسخة قابلة للتثبيت

1) ارفع كل ملفات هذا المجلد إلى مستودع GitHub (في الجذر أو داخل مجلد).
2) فعّل GitHub Pages من Settings > Pages (Deploy from a branch).
3) افتح رابط الموقع على الهاتف بمتصفح Chrome (أندرويد) أو Safari (آيفون).
   - أندرويد: زر "تثبيت التطبيق" يظهر أعلى الصفحة، أو قائمة Chrome > تثبيت التطبيق.
   - آيفون: زر المشاركة > إضافة إلى الشاشة الرئيسية.
4) بعد أول فتح يعمل التطبيق بدون إنترنت.

ملاحظة: التثبيت يحتاج رابط https. فتح index.html مباشرة من الملفات يعمل كصفحة عادية فقط.
البيانات تُحفظ في متصفح الجهاز. استخدم "حفظ نسخة احتياطية" في قسم المواد لنقلها بين الأجهزة.
